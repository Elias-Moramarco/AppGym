# 🏋️‍♂️ Fitness OS

Aplicación multiplataforma (Web, iOS y Android) para la gestión del bienestar personal. Proporciona un entorno intuitivo para registrar actividad física, rutinas y alimentación mediante una interfaz minimalista libre de métricas abrumadoras.

## 🚀 Tecnologías

* **Frontend:** React Native, Expo, React Native Web.
* **Backend & Auth:** Supabase.
* **UI/UX:** Flexbox responsivo y API Animated nativa.
